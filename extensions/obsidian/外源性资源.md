# Obsidian 外源性资源

Obsidian 相关的外源性资源清单，**按功能分类**组织；每项的来源以属性标记：

- `他人` — 他人插件推荐（来自社区插件市场）
- `原创` — 本人仓库
- `fork` — fork 他人仓库、本人维护的版本（注明上游）

简介基于插件市场卡片原文整理；版本号为收录时（2026-08-30）快照；GitHub 链接已逐一核对仓库当前归属。

## 任务与看板

- **Kanban** `他人` — mgmeyers · v2.0.51
  在 Obsidian 中创建基于 Markdown 的看板，笔记组织为可拖拽的列与卡片。
  [GitHub](https://github.com/community-archive/obsidian-kanban)（原 `mgmeyers/obsidian-kanban`，已移交社区归档维护）

- **Tasks** `他人` — Clare Macrae、Ilyas Landikov（原作者 Martin Schenck）· v8.2.2
  在整个仓库中追踪任务：支持截止日期、循环任务、完成日期、清单子集与查询过滤。
  [GitHub](https://github.com/obsidian-tasks-group/obsidian-tasks)

## 编辑与模板

- **Linter** `他人` — Victor Tao · v1.32.0
  格式化与规整笔记：覆盖 YAML 标签/别名/数组/元数据、脚注、标题、空行、数学块及列表、斜体、加粗等正文元素，规则可自定义开关。
  [GitHub](https://github.com/platers/obsidian-linter)

- **Templater** `他人` — SilentVoid · v2.20.6
  类 handlebars 语法的高级模板与自动化插件，支持变量、函数插入及执行 JavaScript。
  [GitHub](https://github.com/SilentVoid13/Templater)

- **Heading Shifter** `他人` — kasahala · v1.11.0
  轻松批量调整 Markdown 标题层级（升降级、指定层级），免逐行手改。
  [GitHub](https://github.com/k4a-l/obsidian-heading-shifter)

- **Code Editor Shortcuts** `他人` — Tim Hor · v1.14.0
  补上 VS Code / Sublime Text 常用快捷键：行插入/复制/删除/合并、多光标、选中下一个匹配等。
  [GitHub](https://github.com/timhor/obsidian-editor-shortcuts)

## 数学与公式

- **Latex Suite** `他人` — artisticat · v1.11.5
  通过代码片段、文本展开与编辑器增强，让 LaTeX 数学排版快如手写（如 `sqx` → `\sqrt{x}`）。
  [GitHub](https://github.com/artisticat1/obsidian-latex-suite)

- **Fix Math** `他人` — Vladislav Sorokin · v1.0.31
  把 ChatGPT 等 AI 助手输出的 LaTeX 公式转为 Obsidian 格式：`\[…\]` → `$$…$$`、`\(…\)` → `$…$`。
  [GitHub](https://github.com/loglux/fix-math-for-obsidian)

## 图表绘制

- **Excalidraw** `他人` — Zsolt Viczián · v2.24.2
  手绘风格白板：在 Obsidian 中编辑、查看 Excalidraw 图画，可嵌入文档并双向链接。
  [GitHub](https://github.com/zsviczian/obsidian-excalidraw-plugin)

- **Excalidraw Extras** `他人` — Zsolt Viczián · v0.0.15
  Excalidraw 配套插件：承载高权限操作与大型组件（MathJax/Mermaid 渲染、文件系统/网络/IPC 访问），保持主插件轻量。
  [GitHub](https://github.com/zsviczian/obsidian-excalidraw-extras)

- **PlantUML** `他人` — Johannes Theiner · v1.8.1
  渲染 PlantUML 图表，支持在线服务器或本地 jar 两种渲染方式。
  [GitHub](https://github.com/joethei/obsidian-plantuml)

- **WaveDrom** `他人` — Alex Stewart · v0.1.1
  在代码块中渲染 WaveDrom 时序波形图（作者自述为快速、尚显粗糙的初版集成）。
  [GitHub](https://github.com/kingsquirrel152/obsidian-wavedrom)

## 图片与媒体

- **Imagine** `他人` — Albus · v1.3.0
  一站式图片管理插件：浏览、检索、引用分析、插入排版、拖拽缩放与全窗查看，支持批量清理无引用图片（仅桌面端）。
  [GitHub](https://github.com/AlbusGuo/albus-imagine)

- **Image in Editor** `他人` — Ozan Tellioglu · v2.2.6
  在编辑器源码模式内直接查看图片、嵌入引用、iframe 与 PDF，无需切换预览。
  [GitHub](https://github.com/ozntel/oz-image-in-editor-obsidian)
