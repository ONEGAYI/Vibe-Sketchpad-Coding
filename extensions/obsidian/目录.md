# Obsidian 扩展目录

`extensions/obsidian/` 的目录索引：本目录既存放**本地小插件**（一插件一子目录，直接入仓），也汇集**外部插件与仓库**。外部条目按功能分类，来源以属性标记：

- `他人` — 他人插件推荐（来自社区插件市场）；**建议直接从插件市场安装**。
- `原创` — 本人仓库
- `fork` — fork 他人仓库、本人维护的版本（注明上游）

简介基于插件市场卡片或仓库 README 整理；版本号为收录时（2026-08-30）快照；GitHub 链接已逐一核对仓库当前归属。

## 本地小插件

直接存放于本目录的插件子目录（kebab-case、自带 `README.md`），新增后在此登记索引。

- **obsidian-html-latex-fix** — 修复阅读视图中 HTML 标签内 LaTeX 公式不渲染的问题（v0.3.0），含自动格式化助手，实时预览模式开发中。见 [obsidian-html-latex-fix/](obsidian-html-latex-fix/)。

## 外部插件与仓库

### 版本控制与备份

- **Git** `他人` — Vinzent（Vinzent03）· v2.39.0
  将 Git 版本控制集成到 Obsidian：自动定时备份与提交、同步远程仓库，实现笔记版本管理与多设备同步。
  [GitHub](https://github.com/Vinzent03/obsidian-git)

### 任务与看板

- **Kanban** `fork` — 上游 mgmeyers（已移交社区归档维护）· v2.0.51
  在 Obsidian 中创建基于 Markdown 的看板，笔记组织为可拖拽的列与卡片。官方版在较新版 Obsidian 下语言检测失效（仅依赖已废弃的 localStorage `language` 键），中文界面会回落英文。
  本人 fork（**推荐优先安装**）：[ONEGAYI/obsidian-kanban](https://github.com/ONEGAYI/obsidian-kanban)，改用官方 API `moment.locale()` 检测语言并补全简中翻译（200/200 键），安装包见 [v2.0.51-zh.1 Release](https://github.com/ONEGAYI/obsidian-kanban/releases/tag/v2.0.51-zh.1)；修复已向上游提交 [PR #1233](https://github.com/community-archive/obsidian-kanban/pull/1233) · 上游：[community-archive/obsidian-kanban](https://github.com/community-archive/obsidian-kanban)

- **Tasks** `他人` — Clare Macrae、Ilyas Landikov（原作者 Martin Schenck）· v8.2.2
  在整个仓库中追踪任务：支持截止日期、循环任务、完成日期、清单子集与查询过滤。
  [GitHub](https://github.com/obsidian-tasks-group/obsidian-tasks)
