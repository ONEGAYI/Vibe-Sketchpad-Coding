# accelerated-learning — 高效学习教练

「accelerated-learning」技能母体本体：以资深教师身份主动引导用户学习一项知识或技能，形成完整学习闭环。

> **本目录即该技能的开发主线**——`~/.agents/skills/accelerated-learning/` 是本机使用副本（主线变更后复制同步）。

## 用途

纯提示词技能，通过系统化教学流程取代一次性知识倾倒：

- **六步学习闭环**：搭建五级学习阶梯 → 筛选约 20% 核心内容 → 逐题考核巩固 → 整理一页速查表 → 筛选五个精选资源 → 费曼法复述检验
- **主动教学**：每轮只推进一个行动，先练习后讲解，按考核结果精准补漏，不机械追求课时数
- **进度管理**：会话内维护进度记录，模块边界安排间隔复习，结束时输出可跨会话复制的学习进度摘要
- **完成标准**：以能独立完成真实任务为准，不以"听懂了"为准

## 用法

无脚本、无命令，`SKILL.md` 即全部内容。技能由 agent 按需自动触发，适用场景：

- 系统学习 / 快速入门一项知识或技能
- 制定学习计划（默认按 20 小时设计核心路径）
- 巩固已学知识、检验掌握程度

不适用于只查询一个孤立事实、或直接代办任务（不给学习过程）的请求。

教学约定（教师职责、启动诊断、六步闭环细则、交互状态块格式）见 [SKILL.md](SKILL.md)。
